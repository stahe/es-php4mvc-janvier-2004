# Un enfoque de desarrollo MVC para aplicaciones web en PHP4

➡️ Curso relacionado: **[Metodología de desarrollo MVC para una aplicación web en PHP4](https://stahe.github.io/es-php4mvc-janvier-2004/)**

Este documento presenta un **enfoque de desarrollo para aplicaciones web PHP basado en la arquitectura MVC (Modelo-Vista-Controlador)**.

El objetivo no es proporcionar un método rígido, sino más bien **ofrecer ideas y un marco** para diseñar aplicaciones web organizadas según el modelo MVC. Cada desarrollador puede entonces adaptar este enfoque **a sus necesidades, herramientas y preferencias de desarrollo**.

## Objetivo del documento

- proponer una **metodología de desarrollo** para aplicaciones web en PHP;
- estructurar una aplicación según el **patrón arquitectónico MVC**
- Aclarar la separación de responsabilidades entre:
  - el **Modelo**: gestión de datos y lógica de negocio;
  - la **Vista**: presentación e interfaz de usuario;
  - el **Controlador**: coordinación de las interacciones entre el Modelo y la Vista;

Este enfoque tiene como objetivo mejorar:

- **la mantenibilidad del código**;
- **la legibilidad de la arquitectura**;
- **la reutilización de componentes**;
- **una clara separación de responsabilidades**;

## Filosofía del enfoque;

La metodología propuesta es intencionadamente **abierta y adaptable**.  
Sirve como **guía de estructuración** más que como un marco estricto.

Cada equipo o desarrollador podrá:

- adaptar las convenciones
- modificar la organización de los componentes
- integrar marcos o bibliotecas adicionales
